# Auditoria SEO inicial — deboralactacao.com

Data: 2026-09-13

## Escopo

Primeira auditoria técnica após a conexão read-only com o Google Search Console.

## Situação encontrada

A landing já possuía título, meta description, Open Graph básico, H1 e conteúdo útil, mas faltavam elementos importantes para indexação e interpretação consistente pelos buscadores:

- canonical do domínio principal;
- robots.txt;
- sitemap.xml;
- og:url e metadados sociais completos;
- Twitter Card;
- JSON-LD estruturado;
- política explícita para impedir indexação de áreas internas, APIs e dashboard;
- camada automática para transformar Search Console em oportunidades priorizadas.

## Correções aplicadas nesta entrega

- canonical `https://deboralactacao.com/`;
- title e description refinados para a intenção principal sem promessas clínicas;
- Open Graph completo com URL e imagem absoluta;
- Twitter Card;
- JSON-LD com WebSite, Person, Service e FAQPage baseado no conteúdo visível;
- `robots.txt` permitindo o rastreamento das páginas HTML e bloqueando apenas endpoints/preview que não precisam ser rastreados;
- `sitemap.xml` contendo apenas a URL pública canônica;
- `X-Robots-Tag: noindex, nofollow` para `/api`, `/app`, `/admin` e `/clinical-source`;
- dashboard administrativo marcado com `noindex,nofollow`;
- auditoria automática de Search Console para detectar CTR baixo e termos em posições 4–20.

Páginas HTML privadas permanecem rastreáveis para que o robô consiga ler a diretiva `noindex`; elas não entram no sitemap.

## Regras da auditoria automática

A API SEO passa a sinalizar, entre os principais dados retornados pelo Search Console:

- busca com pelo menos 50 impressões e CTR abaixo de 2,5% → oportunidade de melhorar snippet;
- busca com pelo menos 30 impressões e posição média entre 4 e 20 → oportunidade de ranking;
- página com pelo menos 100 impressões e CTR abaixo de 2,5% → oportunidade de melhorar apresentação no Google.

Esses limites são heurísticas iniciais e podem ser calibrados conforme o volume real de dados crescer.

## Limites deliberados

- nenhuma alteração clínica é publicada automaticamente;
- nenhuma promessa de resultado é adicionada ao conteúdo;
- mudanças maiores de copy continuam exigindo aprovação;
- dados e tokens do Search Console permanecem somente no backend.
